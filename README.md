# フリマ手数料・利益計算機

メルカリ・Yahoo!フリマ・ラクマ・Amazonの手数料と利益を一括で比較できる、無料のWeb計算機です。

**公開ページ**: https://ユーザー名.github.io/furima-calc/

## できること

- 販売価格・仕入れ原価・送料・その他経費から、サービスごとの手数料・手取り・利益・利益率を並べて比較
- 目標利益から、必要な販売価格を逆算
- 手数料率と固定費の編集（ブラウザに保存されます）
- スマートフォン（iPhone/Android）に対応、ダークモード対応

## プライバシー

すべての計算はブラウザ内で行われます。入力した金額が外部サーバーに送信されることはありません。手数料率の設定のみ、お使いのブラウザのlocalStorageに保存されます。

## 手数料率の初期値

| サービス | 初期値 | 備考 |
|---|---|---|
| メルカリ | 10% | |
| Yahoo!フリマ | 5% | |
| ラクマ | 10% | 要確認 |
| Amazon | 15% | カテゴリにより異なります。FBA手数料や月額プランは含みません |

手数料率は改定されることがあります。**必ず各サービスの公式ヘルプで最新の料率を確認してください。** 画面内の「手数料率を編集する」から変更できます。

## 含まれないもの

- 振込手数料
- キャンペーン、クーポン、ポイント
- 消費税の詳細な扱い、所得税などの税金
- eBayなど海外マーケットプレイス

## 免責事項

計算結果は参考値です。実際の手数料・手取り額と異なる場合があります。本ツールの利用により生じた損害について、作者は責任を負いません。
